# SWYNEX-Biological-Dataset-Selection

Dataset - _Leptodirus_hochenwartii_ (Narrow-necked blind cave beetle) genome

**Source**

NCBI BioProject database - PRJEB57371 (BioProject ID: 899775).

Generated by the Wellcome Sanger Institute as part of the European Reference Genome Atlas (ERGA) Pilot Project as 
an initiative to sequence the genomes of European eukaryotic species for biodiversity and conservation research.


**Size**

Total length - 492.36 megabases (Mb)

98.03% is scaffolded into 14 chromosomal pseudomolecules, including the X and Y sex chromosomes.
The mitochondrial genome has also been assembled and is 22.01 kilobases (kb) in length.
The primary assembly accession is GCA_947310685.1.


**Research Question**

_Leptodirus_hochenwartii_ is a strictly cave-dwelling (troglobitic) species that exhibits typical adaptations such 
as blindness, depigmentation, and elongated appendages.
Sangar Institute produced a high-quality reference genome for this cave-adapted beetle to facilitate research into 
the genetic basis of cave adaptation and specialized traits.

**My project aims to investigate the molecular changes associated with such evolutionary adaptations.**
